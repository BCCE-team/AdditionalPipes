# Additional Pipes Community Edition

Additional Pipes Community Edition expands BuildCraft Community Edition with additional pipes and advanced transportation mechanics, bringing back the functionality of the classic Additional Pipes addon.

The addon introduces specialized pipes for item distribution, advanced sorting, teleportation, fluid transportation, and automation, allowing players to build more complex and efficient transport networks.

An unofficial community-maintained port of Additional Pipes for BuildCraft Community Edition, developed by the BCCE team.

## Changes

This fork does not intentionally change the original gameplay or introduce unrelated gameplay features. Its main purpose is to port Additional Pipes to newer Minecraft versions and integrate it with BuildCraft Community Edition.

The project aims to preserve the original pipe mechanics, recipes, and behavior while adapting them to modern Minecraft systems and BCCE API v2.

Some original features are still being ported and may not yet be available.

## Supported versions

The following Minecraft versions and mod loaders are targeted:

- Minecraft 1.19.2 — Forge
- Minecraft 1.20.1 — Forge
- Minecraft 1.21.1 — NeoForge
- Minecraft 1.21.11 — NeoForge
- Minecraft 26.1.2 — NeoForge
- Minecraft 26.2 — NeoForge
- Minecraft 26.3 — NeoForge

Support for individual versions and features is being developed progressively.

**BuildCraft Community Edition is required to run this addon.**
